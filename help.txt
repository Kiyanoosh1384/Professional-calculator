                         ABOUT THIS CALCULATOR

================================================================================

This advanced mathematical calculator is a powerful tool that supports a 
wide range of mathematical operations, including:

1.  BASIC ARITHMETIC:
    - Addition (+), Subtraction (-), Multiplication (*)
    - Division (/), Floor Division (//), Modulo (%)
    - Power (** or ^)

2.  ADVANCED MATHEMATICAL FUNCTIONS:
    - Factorial (!), Percentage (%)
    - Square Root (sqrt or sqr), Cube Root (cbrt), nth Root (root(n, x))
    - Logarithm (ln, log, log10, log2, log(x, base))
    - Exponential (exp)
    - Trigonometric Functions (sin, cos, tan, cot, sec, csc)
    - Inverse Trigonometric Functions (asin, acos, atan)
    - Hyperbolic Functions (sinh, cosh, tanh, coth, sech, csch)

3.  ALGEBRA & EQUATIONS:
    - Linear Equations (ax + b = 0)
    - Quadratic Equations (ax² + bx + c = 0)
    - Cubic Equations (ax³ + bx² + cx + d = 0)

4.  NUMBER THEORY:
    - Prime Number Check & Prime Factorization
    - Divisors and Sum of Divisors
    - Euler's Totient Function (phi)
    - GCD and LCM
    - Fibonacci Sequence
    - Perfect, Abundant, and Deficient Numbers
    - Next Prime Number

5.  STATISTICS:
    - Mean, Median, Mode
    - Variance and Standard Deviation
    - Quartiles and Interquartile Range (IQR)
    - Min, Max, Range, Count, and Sum

6.  LINEAR ALGEBRA:
    - 2x2 and 3x3 Determinants
    - 2x2 Matrix Inverse
    - Matrix Transpose
    - Matrix Multiplication, Addition, and Subtraction
    - Scalar Multiplication

7.  GEOMETRY:
    - 2D Shapes: Square, Rectangle, Parallelogram, Rhombus, Triangle,
      Equilateral, Isosceles, Right Triangle, Trapezoid, Pentagon,
      Hexagon, Octagon, Circle, Ellipse
    - 3D Shapes: Cube, Cuboid, Sphere, Cylinder, Pyramid, Cone

8.  NUMBER SYSTEMS:
    - Binary to Decimal Conversion
    - Decimal to Binary Conversion
    - Hexadecimal to Decimal Conversion
    - Decimal to Hexadecimal Conversion
    - Octal to Decimal Conversion
    - Decimal to Octal Conversion

9.  PROBABILITY:
    - Binomial Probability
    - Poisson Probability
    - Permutations
    - Combinations

================================================================================

                      HOW TO USE THIS CALCULATOR

================================================================================

1.  Starting the Calculator:
    Run the Python script: python calculator.py
    The main menu will appear with 8 options.

2.  Basic Calculator (Option 1):
    - Enter mathematical expressions directly
    - Use 'q' to return to the main menu
    - Examples:
      > 2 + 3 * 4
      > sqrt(144)
      > 5!
      > sin(30)
      > ln(e)
      > log(1024, 2)
      > pi * 5^2

3.  Algebra & Equations (Option 2):
    - Solve Linear, Quadratic, or Cubic equations
    - Enter coefficients when prompted
    - Use 'q' to return to the main menu

4.  Number Theory (Option 3):
    - Various number theory operations
    - Follow the prompts for each operation
    - Use 'q' to return to the main menu

5.  Statistics (Option 4):
    - Enter numbers separated by space
    - View comprehensive statistical analysis
    - Use 'q' to return to the main menu

6.  Linear Algebra (Option 5):
    - Matrix operations including addition, subtraction,
      multiplication, determinant, inverse, and transpose
    - Enter matrices in the format [[a,b],[c,d]]
    - Use 'q' to return to the main menu

7.  Geometry (Option 6):
    - Select 2D or 3D shapes from the menu
    - Enter required dimensions
    - View calculated results
    - Use 'q' to return to the main menu

8.  Number Systems (Option 7):
    - Convert between different number systems
    - Use 'q' to return to the main menu

9.  Probability (Option 8):
    - Calculate binomial and poisson probabilities
    - Calculate permutations and combinations
    - Use 'q' to return to the main menu

================================================================================

                     IMPORTANT NOTES & TIPS

================================================================================

1.  All trigonometric functions work in DEGREES by default.
2.  Use 'pi' for the mathematical constant π.
3.  Use 'e' for Euler's number.
4.  Use '^' for power operations (e.g., 2^3 = 8).
5.  For logarithm with custom base: log(x, base)
6.  For natural logarithm: ln(x)
7.  Matrices should be entered in the format: [[a,b],[c,d]]
8.  For nth root: root(n, x)
9.  For factorial: number! (e.g., 5!)
10. For percentage: number% (e.g., 50% = 0.5)

================================================================================

                      نحوه استفاده از این ماشین حساب

================================================================================

1.  شروع ماشین حساب:
    اسکریپت پایتون را اجرا کنید: python calculator.py
    منوی اصلی با ۸ گزینه نمایش داده می‌شود.

2.  ماشین حساب پایه (گزینه ۱):
    - عبارات ریاضی را مستقیماً وارد کنید
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید
    - مثال‌ها:
      > 2 + 3 * 4
      > sqrt(144)
      > 5!
      > sin(30)
      > ln(e)
      > log(1024, 2)
      > pi * 5^2

3.  جبر و معادلات (گزینه ۲):
    - حل معادلات خطی، درجه دوم یا درجه سوم
    - ضرایب را هنگام درخواست وارد کنید
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید

4.  نظریه اعداد (گزینه ۳):
    - عملیات مختلف نظریه اعداد
    - دستورالعمل‌های هر عملیات را دنبال کنید
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید

5.  آمار (گزینه ۴):
    - اعداد را با فاصله وارد کنید
    - تحلیل آماری جامع را مشاهده کنید
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید

6.  جبر خطی (گزینه ۵):
    - عملیات ماتریسی شامل جمع، تفریق، ضرب، دترمینان، معکوس و ترانهاده
    - ماتریس‌ها را به فرمت [[a,b],[c,d]] وارد کنید
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید

7.  هندسه (گزینه ۶):
    - اشکال ۲ بعدی یا ۳ بعدی را از منو انتخاب کنید
    - ابعاد مورد نیاز را وارد کنید
    - نتایج محاسبه شده را مشاهده کنید
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید

8.  سیستم‌های عددی (گزینه ۷):
    - تبدیل بین سیستم‌های عددی مختلف
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید

9.  احتمال (گزینه ۸):
    - محاسبه احتمالات دوجمله‌ای و پواسون
    - محاسبه جایگشت و ترکیب
    - برای بازگشت به منوی اصلی از 'q' استفاده کنید
